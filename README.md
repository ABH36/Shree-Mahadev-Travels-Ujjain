# Shree Mahadev Travels Ujjain

Official website for **Shree Mahadev Travels Ujjain** — Your Trusted Travel Partner in Ujjain. Offering reliable and affordable taxi and cab booking services in Ujjain, Omkareshwar, Indore, Maheshwar, Mandu, Sehore, and nearby pilgrim destinations.

## 🚀 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React & Custom Animated Assets
- **Deployment**: Vercel / Node.js

## 🚖 Features

- **Hero Banner**: High-impact auto-sliding banner with call-to-action buttons.
- **Booking Form**: Direct booking form with enquiry integration, dark bold placeholders, and auto-populated vehicle selections.
- **Tourist Destinations**: Interactive auto-swapping cards showcasing Ujjain, Omkareshwar, Maheshwar, Mandu, Baglamukhi Nalkheda, Kubereshwar Mahadev Sehore, and Indore Sightseeing.
- **Fleet Showcase**: Comprehensive view of vehicles (Swift Dzire, Ertiga, Innova Crysta) with seating capacity and AC details.
- **Responsive Design**: Optimized for desktop, tablet, and mobile screens with custom floating WhatsApp & Scroll-To-Top controls.

## 🛠️ Local Development

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Production Build

To build the production bundle:

```bash
npm run build
npm run start
```
